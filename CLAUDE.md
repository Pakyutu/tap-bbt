# Catatan
- Setiap update data dashboard, perbarui juga tanggal di `status.json` (ditampilkan di menu utama sebagai Status data).
- Naikkan versi cache `V` di `sw.js` tiap deploy.
- Cek WL vs ST: data dari `tools/cekst_build.py --wl WL.xlsx [--add WL_baru.xlsx ...] [--byu WL_SA_BYU.xlsx] --pv raw_st_pv*.xlsx --sa raw_st_sp*.xlsx` -> `cekst-data.js`, update juga status.json. `--add` = WL dropingan format baru (sheet VF/SA/WL Return): SN return dikeluarkan dari VF NOV, SN baru ditambah/ganti SF.
- ST Digipos: `python3 tools/st_digipos.py <ST_DIGIPOS.xlsx>` (update kolom vr/vb/ss/sb D.O di digipos.html), lalu ganti label "update DD Nov" + D.VER.
- MoM Sales Tap (paste SURYA): `python3 tools/surya_mom.py <paste.txt> PV|SA <hari>`.
- Stock on Hand (paste SURYA): `python3 tools/surya_soh.py <paste.txt> PV|SA <hari_MTD> <hari_paste>`.
- Revenue Telkomsel per site (Monitoring Performance Region SUMBAGTENG): `python3 tools/site_rev.py <file.xlsx> "DD Nov"` (tanggal = Data Update di sheet SITE LEVEL).
- Cuan PV Redeem (sheet "Reedem PV" di file Monitoring Klik Misi & FR, atau file CUAN_PV_Redeem_YYYYMMDD sheet Summary): `python3 tools/cuan_pv.py <file.xlsx> "DD Nov"` -> digipos-cuan.js, update status.json.
- Desain "Titik Gerak": token & gaya global di `ui.css` (dipasang di semua halaman, memetakan variabel lama --bg/--card/--tx/--mu/--bd/--ac dst). Navigasi bawah di `nav.js`. Halaman baru wajib pakai ui.css + nav.js.
- SN terpakai (tidak bisa di-ST lagi) dicatat di `tools/cekst_terpakai.txt` → otomatis tidak dihitung di Cek WL. Tanpa build ulang: `python3 tools/cekst_terpakai_apply.py`.
- Outlet PV/SA/NGRS (export SURYA csv): `python3 tools/surya_outlet.py --pv Detail_Outlet_PV_*.csv --sa Detail_Outlet_SA_*.csv --ngrs NGRS_2026_TRX.csv` (cutoff dari header "2026-10 MoM 1-DD"), update status.json. CVM: cek dulu, kalau Nov program masih 0 jangan dimasukkan.
- Stock Gudang per SF (export SURYA Stock_Gudang_SF_*.csv): `python3 tools/surya_sgsf.py <csv> <tgl>` -> X.SGF BBT + TAPJ[BAA|UJT].SGF (satu file semua TAP; kartu "Stok lengkap per SF" di tab Stok, melengkapi Stock on Hand).
- Stock Gudang TAP (export SURYA Stock_Gudang_ALL_*.csv): `python3 tools/surya_sgall.py <csv> <tgl>` -> D.STK snapshot.
- ST per outlet juga bisa dari file "Monitoring ST Product <bulan> Cluster Rohil": `python3 tools/st_product.py <file.xlsx>` (pakai yang paling baru antara ini dan ST_DIGIPOS), lalu ganti label "update DD Nov" + D.VER.
- Extra Dealing Misi (file Dealing_EXTRA_*.xlsx, sheet Raw + Sheet1): `python3 tools/extra_dealing.py <file.xlsx> "DD Nov"` -> digipos-xd.js (tab 🎯 Extra Dealing), update status.json.
- Sultan Spesial SO (file Monitoting_Program_Dealing_Misi_Sultan_Spesial_SO.xlsx, sheet Raw): `python3 tools/sultan_so.py <file.xlsx> "DD Nov"` -> digipos-sso.js. Tab DIGIPOS dikelompokkan di `digipos-nav.js` (grup Ringkasan/Wilayah/Outlet/Program/Scan); tab baru tambahkan ke array G.
- Grup tab: `tabgroup.js` generik (config window.TABG sebelum dimuat). DIGIPOS config di digipos-nav.js (juga header ringkas: ⚙️ Filter + menu ⋯); Penjualan config inline sebelum tabgroup.js. Tab baru otomatis masuk grup terakhir kalau tidak didaftarkan.
- Biometrik & FR Top 20 (file Outlet_Biometrik_Sumbagteng_2026_*.xlsx, sheet trx + Sheet1): `python3 tools/biometrik.py <file.xlsx> "DD Nov"` -> CV.v[4] di digipos-cvm.js + D.FR di digipos.html, update status.json (Biometrik, FR Biometric).
- Umur SN belum ST (Cek WL): peta tanggal drop CK.DM dibuat otomatis oleh cekst_build.py; tanpa build ulang: `python3 tools/cekst_dm.py --wl ... --add ...`.
- MoM per varian (tab Petugas, pilihan Semua/Reguler/By.U): `python3 tools/surya_mom.py <paste.txt> PV|SA <hari> R|B|S` (PV: R=Reguler,B=By.U; SA: S=Simpati,B=By.U) -> D.P['PVR'|'PVB'|'SAS'|'SAB']; tidak mengubah TM/TI/SV. Sumber: dashboard SURYA, filter Produk di "MoM Sales Tap" (URL `?mom_date=YYYY-MM-DD&mom_product=pv_reg|pv_byu|sa_simpati|sa_byu`).
- Redeem vs ST semua TAP (laporan Branch "VF <tgl>", tab Kecamatan): `python3 tools/rv_tap.py <paste.txt> <hari>` -> RV/RX[hari] (BBT) + RVT/RXT[BAA|UJT|ALL] di digipos-x.js, termasuk varian By.U/Simpati/Unlimited (rv_varian.py = BBT lama).
- Multi-TAP (Rohil): pilihan TAP di header Digipos (`?tap=BBT|BAA|UJT|ALL`, disimpan di localStorage). BBT = D.O di digipos.html; BAA/UJT dari `data-tap.js` (`python3 tools/tap_master.py <Outletlist_*.xlsx>`, filter KET PJP=1, target = rasio BBT/perkiraan). ST, Klik Misi, Extra Dealing, Sultan SO, Cuan PV, Biometrik/FR berlaku semua TAP (script memakai `tools/tapids.py`, kunci per ID outlet). Site semua TAP: `python3 tools/site_pjp.py <Update_PJP_dan_Site_*.xlsx>` lalu `site_rev.py`. Penjualan per TAP (pilihan TAP di header, `?tap=`): outlet PV/SA/NGRS BAA & UJT dari `data-tap-pj.js` (`python3 tools/pj_tap.py --pv ... --sa ... --ngrs ...`, satu cutoff terbaru; jalankan bersama `surya_outlet.py` untuk BBT). MoM Petugas BAA & UJT dari SURYA: ekstrak JSON lalu `python3 tools/mom_tap.py <dir> 21` (PV/SA semua hari, varian hanya hari terakhir); Stok per TAP lewat `surya_sgall.py`. Stock on Hand BAA & UJT (SURYA stock-on-hand, filter tap, PV+SA; ekstrak ke JSON lewat browser) -> `python3 tools/soh_tap.py <soh.json> <hari_paste> <hari_MTD> <sisa_HK>` -> TAPJ[k].SOHV/SOHS; tab Stok (matriks SF×validity) & Target SF berlaku semua TAP (ALL = BBT+BAA+UJT), kartu "Stok lengkap per SF" BAA & UJT dari SURYA stock-gudang mode SF (ekstrak JSON lewat browser) -> `python3 tools/sgf_tap.py <sgf.json> <tgl>` -> TAPJ[k].SGF; kartu stok per validity ikut TAP (ALL = jumlah snapshot terbaru tiap TAP). Tren bulanan per petugas & inject vs penjualan (semua TAP): ekstrak tabel Penjualan Bulanan/Inject Bulanan/MoM per Validity (PV ALL) dari SURYA ke JSON lalu `python3 tools/mx_tap.py <ekstrak.json> <hari>` -> data-tap-mx.js (window.TAPMX; ALL = jumlah 3 TAP; menimpa X.TM/TI/PM/INJ/SVM/SV di penjualan-x.js). Target SF, Barcode, CVM (export SURYA semua TAP, Nov program harus terisi) berlaku semua TAP. Prinsip: semua fitur baru harus jalan untuk BBT/BAA/UJT/ALL (Cluster Rohil), bukan BBT saja.

- Cek WL BAA/UJT vs ST (raw ST memuat semua TAP): setelah `wl_tap.py` (dropingan -> wl-tap.js), jalankan `python3 tools/cekst_tap.py --pv raw_st_pv*.xlsx --sa raw_st_sp*.xlsx` -> CK.TAP[tap] di cekst-data.js (tampilan sama dengan BBT; `cekst_build.py` mempertahankan CK.TAP). UJT menunggu file dropingan.
- Koreksi manual site ID outlet: `tools/site_override.txt` (`<ID outlet> <site>`), otomatis dipakai `site_pjp.py` supaya tidak tertimpa file PJP baru. Saat ini: Pegasus Cellular (1201061183) = UJT504.
