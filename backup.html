Backup Data

Simpan semua data aplikasi di HP ini jadi satu file, lalu pulihkan di HP baru. Data tidak dikirim ke server mana pun.

Data di HP ini

1. Backup (HP lama)

Buat file backup, lalu kirim ke HP baru lewat WhatsApp ke nomor sendiri, Google Drive, atau kabel data.

2. Pulihkan (HP baru)

Pilih file TAP-BBT-backup-….json yang dikirim dari HP lama.

Cara pindah ke HP baru

  1. Di HP lama, buka menu ini lalu ketuk Backup & kirim. Kirim file-nya ke WhatsApp sendiri atau simpan ke Drive.
  2. Di HP baru, buka pakyutu.github.io/tap-bbt lalu install aplikasinya.
  3. Download file backup dari WhatsApp/Drive di HP baru.
  4. Buka menu Backup Data → Pilih file backup → Pulihkan.
